Datenschutzerklärung

Diese Erklärung gilt für die private Anwendung „LUMO Backup“. Sie wird ausschließlich von ihrem Inhaber genutzt.

Welche Daten die Anwendung nutzt

Die Anwendung verwendet nur den Google-Drive-Bereich drive.file. Damit kann sie ausschließlich Dateien lesen und schreiben, die sie selbst angelegt hat – keine anderen Dateien im Google Drive. Diese Dateien sind verschlüsselte Sicherungskopien (restic) der eigenen Daten des Inhabers; ihren Inhalt kann auch Google nicht lesen.

Wofür

Ausschließlich zur Datensicherung: Sicherungskopien anlegen, prüfen, nach den eigenen Aufbewahrungsregeln aufräumen und bei Bedarf wiederherstellen.

Keine Weitergabe

Die Daten werden nur auf dem eigenen Server des Inhabers und in seinem eigenen Google Drive verarbeitet. Es gibt keine Weitergabe an Dritte, keinen Verkauf, keine Werbung, kein Tracking und keine Auswertung. Diese Website setzt keine Cookies und lädt keine fremden Inhalte.

Google-API-Richtlinie

Die Nutzung von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Speicherdauer, Widerruf und Kontakt

Sicherungskopien werden nach den eigenen Aufbewahrungsregeln des Inhabers gelöscht. Der Zugriff der Anwendung lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Kontakt: über das GitHub-Profil, unter dem diese Seite veröffentlicht ist.

English summary

LUMO Backup is used only by its owner. It requests only the drive.file scope, so it can access only files it created itself: encrypted backups (restic) of the owner's own data. Data is processed only on the owner's own server and in the owner's own Google Drive. Nothing is shared, sold, used for advertising or analysed. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: via the GitHub profile this page is published under.
